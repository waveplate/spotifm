# Spotifm 3.3.2

- After Spotify authorization, open the player over HTTPS for hostnames other
  than `127.0.0.1`. The redirect keeps the callback hostname and uses `tls_port`
  (3443 by default). Local access at `127.0.0.1` can still use HTTP.
- Fix a visualizer startup race so the renderer receives audio on first play.
- Switch Milkdrop presets on song changes by default.
- Improve lyric timing for the first demo sample.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/waveplate/spotifm/v3.3.2/install.sh | bash -s -- --version 3.3.2
```

The release includes `spotifm-linux-x86_64-musl.tar.gz` with the static binary
and player assets, plus its SHA-256 checksum.

```sh
docker pull waveplate/spotifm:3.3.2
SPOTIFM_IMAGE=waveplate/spotifm:3.3.2 docker compose up -d spotifm
```

Docker tags `3.3.2` and `latest` select this release.
