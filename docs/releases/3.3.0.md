# Spotifm 3.3.0

Spotifm 3.3.0 promotes the current beta to a stable release. It includes the
standalone audio streamer, configurable web player with Milkdrop and NTSC/VHS
effects, timed lyrics with LRCLIB fallback, and anonymous Spotify search
fallback introduced in the beta series.

## Changes since 3.2.0-beta

- Fix cross-origin browser requests across the API, player, audio stream, and
  lyrics endpoints on both HTTP and HTTPS, including the authorization gateway.
- Handle preflight requests with the supported API methods and request headers,
  and preserve CORS headers on API error responses.
- Expose retry, search-source, and Ogg timing headers to browser clients.
- Add `cors_origins` configuration and the `--cors-origins` CLI option. All
  origins are allowed by default; an explicit list restricts browser origins.
- Host the standalone player demo alongside the API documentation and link it
  from the README.

See [CORS configuration](../configuration.md#cross-origin-requests-cors) for
examples and [the previous release notes](3.2.0-beta.md) for the beta's features.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/waveplate/spotifm/v3.3.0/install.sh | bash -s -- --version 3.3.0
```

The release includes an x86-64 Linux static musl archive, bundled player assets,
and SHA-256 checksums. The installer defaults to this stable release.

```sh
docker pull waveplate/spotifm:3.3.0
```

Docker tags `3.3.0` and `latest` select this release. The existing `beta` tag
continues to select 3.2.0-beta.

```sh
SPOTIFM_IMAGE=waveplate/spotifm:3.3.0 docker compose up -d spotifm
```
