# Spotifm 3.3.1

Spotifm 3.3.1 removes the lyrics-provider label from the player, fixes the
post-login redirect, and makes Web API authorization optional through config.

## Changes since 3.3.0

- Remove the Spotify/LRCLIB lyrics-source badge from the main player, minimal
  player, and demo.
- Automatically open the configured web player after OAuth and startup finish.
  Preserve the callback request's hostname and the public origin when using a
  reverse proxy. Direct callbacks on a dedicated listener switch to the player
  port on the same hostname.
- Use `client_id` for playback OAuth and the librespot session, defaulting to
  `65b708073fc0480ea92a077233ca87bd` even without a config file.
- Make Web API access opt-in through `rspotify_client_id`, with a separate
  `rspotify_redirect_uri`. Both examples are commented out in shipped and
  generated configs. When unset, use anonymous search and playback-session
  metadata directly, without loading or refreshing Web API tokens.
- Keep Cargo downloads and compiled dependencies in persistent Docker volumes
  for repeated musl builds, alongside a reusable native-library/toolchain stage.

## Configuration migration

Replace `playback_client_id` with `client_id`. If you want Web API access, move
the previous Web API ID to `rspotify_client_id` and configure its callback
separately:

```toml
client_id = "65b708073fc0480ea92a077233ca87bd"
redirect_uri = "http://127.0.0.1:8898/login"
# rspotify_client_id = "d420a117a32841c2b3474932e49fb54b"
# rspotify_redirect_uri = "http://127.0.0.1:8899/ncspot_login"
```

Leave the rspotify settings commented out to use the catalogue fallback.
If you enable them in Docker with the default callback, publish port 8899 too.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/waveplate/spotifm/v3.3.1/install.sh | bash -s -- --version 3.3.1
```

The release includes the static x86-64 Linux musl archive and bundled player,
`spotifm-linux-x86_64-musl.tar.gz`, plus its SHA-256 checksum.

```sh
docker pull waveplate/spotifm:3.3.1
SPOTIFM_IMAGE=waveplate/spotifm:3.3.1 docker compose up -d spotifm
```

Docker tags `3.3.1` and `latest` select this release. The `beta` tag is unchanged.
